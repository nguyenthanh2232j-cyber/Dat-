const express = require('express'); const sqlite3 = require('sqlite3').verbose(); const bcrypt = require('bcryptjs'); const jwt = require('jsonwebtoken'); const cors = require('cors'); const path = require('path'); const app = express(); const PORT = 3000; const JWT_SECRET = 'secret_key_123'; app.use(cors()); app.use(express.json()); // ================= 1. THIẾT LẬP DATABASE SQLITE ================= const db = new sqlite3.Database('./gameshop.db'); // Hàm hỗ trợ Promise cho SQLite const dbRun = (sql, params = []) => new Promise((resolve, reject) => { db.run(sql, params, function(err) { if (err) reject(err); else resolve(this); }); }); const dbGet = (sql, params = []) => new Promise((resolve, reject) => { db.get(sql, params, (err, result) => { if (err) reject(err); else resolve(result); }); }); const dbAll = (sql, params = []) => new Promise((resolve, reject) => { db.all(sql, params, (err, rows) => { if (err) reject(err); else resolve(rows); }); }); // Khởi tạo Database & Dữ liệu mẫu async function initDatabase() { await dbRun(`CREATE TABLE IF NOT EXISTS users ( id INTEGER PRIMARY KEY AUTOINCREMENT, username TEXT UNIQUE, password_hash TEXT, role TEXT )`); await dbRun(`CREATE TABLE IF NOT EXISTS wallets ( id INTEGER PRIMARY KEY AUTOINCREMENT, user_id INTEGER UNIQUE, balance REAL DEFAULT 0, FOREIGN KEY(user_id) REFERENCES users(id) )`); await dbRun(`CREATE TABLE IF NOT EXISTS products ( id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT, price REAL, image_url TEXT )`); await dbRun(`CREATE TABLE IF NOT EXISTS orders ( id INTEGER PRIMARY KEY AUTOINCREMENT, user_id INTEGER, product_id INTEGER, total_amount REAL, created_at DATETIME DEFAULT CURRENT_TIMESTAMP, FOREIGN KEY(user_id) REFERENCES users(id), FOREIGN KEY(product_id) REFERENCES products(id) )`); await dbRun(`CREATE TABLE IF NOT EXISTS transactions ( id INTEGER PRIMARY KEY AUTOINCREMENT, user_id INTEGER, amount REAL, type TEXT, FOREIGN KEY(user_id) REFERENCES users(id) )`); // Tạo tài khoản mẫu nếu chưa tồn tại const adminExist = await dbGet(`SELECT id FROM users WHERE username = 'admin'`); if (!adminExist) { const hash = await bcrypt.hash('123456', 10); await dbRun(`INSERT INTO users (username, password_hash, role) VALUES (?, ?, ?)`, ['admin', hash, 'admin']); const adminId = (await dbGet(`SELECT id FROM users WHERE username = 'admin'`)).id; await dbRun(`INSERT INTO wallets (user_id, balance) VALUES (?, ?)`, [adminId, 5000000]); } const userExist = await dbGet(`SELECT id FROM users WHERE username = 'userdemo'`); if (!userExist) { const hash = await bcrypt.hash('123456', 10); await dbRun(`INSERT INTO users (username, password_hash, role) VALUES (?, ?, ?)`, ['userdemo', hash, 'user']); const userId = (await dbGet(`SELECT id FROM users WHERE username = 'userdemo'`)).id; await dbRun(`INSERT INTO wallets (user_id, balance) VALUES (?, ?)`, [userId, 1000000]); } // Tạo sản phẩm mẫu const productExist = await dbGet(`SELECT id FROM products LIMIT 1`); if (!productExist) { await dbRun(`INSERT INTO products (name, price, image_url) VALUES (?, ?, ?)`, ['Grow A Garden Token', 15000, 'https://via.placeholder.com/60/2d3748/fff?text=Garden']); await dbRun(`INSERT INTO products (name, price, image_url) VALUES (?, ?, ?)`, ['Robux 100', 20000, 'https://via.placeholder.com/60/1a202c/fff?text=Roblox']); } console.log('✅ Database và dữ liệu mẫu đã được khởi tạo thành công!'); } initDatabase(); // ================= 2. CÁC API (BACKEND) ================= // Xác thực Token const authenticate = (req, res, next) => { const token = req.headers.authorization?.split(' ')[1]; if (!token) return res.status(401).json({ msg: 'Vui lòng đăng nhập' }); try { req.user = jwt.verify(token, JWT_SECRET); next(); } catch (err) { return res.status(401).json({ msg: 'Token hết hạn' }); } }; // Đăng nhập app.post('/api/auth/login', async (req, res) => { const { username, password } = req.body; const user = await dbGet(`SELECT * FROM users WHERE username = ?`, [username]); if (!user) return res.status(400).json({ msg: 'Sai tài khoản/mật khẩu' }); const valid = await bcrypt.compare(password, user.password_hash); if (!valid) return res.status(400).json({ msg: 'Sai tài khoản/mật khẩu' }); const wallet = await dbGet(`SELECT balance FROM wallets WHERE user_id = ?`, [user.id]); const token = jwt.sign({ id: user.id, role: user.role }, JWT_SECRET, { expiresIn: '7d' }); res.json({ token, user: { id: user.id, username: user.username, role: user.role, balance: wallet?.balance || 0 } }); }); // API User: Lấy sản phẩm app.get('/api/user/products', async (req, res) => { const products = await dbAll(`SELECT * FROM products`); res.json(products); }); // API User: Nạp tiền app.post('/api/user/deposit', authenticate, async (req, res) => { const { amount } = req.body; const userId = req.user.id; await dbRun(`UPDATE wallets SET balance = balance + ? WHERE user_id = ?`, [amount, userId]); await dbRun(`INSERT INTO transactions (user_id, amount, type) VALUES (?, ?, ?)`, [userId, amount, 'deposit']); res.json({ msg: `Nạp thành công ${amount.toLocaleString()}đ!` }); }); // API User: Mua hàng (Dùng Transaction SQLite) app.post('/api/user/buy', authenticate, async (req, res) => { const { productId } = req.body; const userId = req.user.id; const product = await dbGet(`SELECT price FROM products WHERE id = ?`, [productId]); if (!product) return res.status(404).json({ msg: 'Sản phẩm không tồn tại' }); const wallet = await dbGet(`SELECT balance FROM wallets WHERE user_id = ?`, [userId]); if (wallet.balance < product.price) { return res.status(400).json({ msg: 'Số dư không đủ' }); } // Thực hiện giao dịch tuần tự await dbRun(`UPDATE wallets SET balance = balance - ? WHERE user_id = ?`, [product.price, userId]); await dbRun(`INSERT INTO orders (user_id, product_id, total_amount) VALUES (?, ?, ?)`, [userId, productId, product.price]); await dbRun(`INSERT INTO transactions (user_id, amount, type) VALUES (?, ?, ?)`, [userId, product.price, 'purchase']); res.json({ msg: 'Mua hàng thành công!' }); }); // API User: Lịch sử app.get('/api/user/history', authenticate, async (req, res) => { const list = await dbAll(`SELECT * FROM transactions WHERE user_id = ? ORDER BY id DESC`, [req.user.id]); res.json(list); }); // API Admin: Thống kê app.get('/api/admin/stats', authenticate, async (req, res) => { if (req.user.role !== 'admin') return res.status(403).json({ msg: 'Cấm truy cập' }); const users = (await dbGet(`SELECT COUNT(*) as count FROM users WHERE role = 'user'`)).count; const orders = (await dbGet(`SELECT COUNT(*) as count FROM orders`)).count; const revenue = (await dbGet(`SELECT IFNULL(SUM(total_amount), 0) as sum FROM orders`)).sum; res.json({ users, orders, revenue }); }); // API Admin: Danh sách User app.get('/api/admin/users', authenticate, async (req, res) => { if (req.user.role !== 'admin') return res.status(403).json({ msg: 'Cấm truy cập' }); const list = await dbAll(`SELECT u.id, u.username, u.role, w.balance FROM users u LEFT JOIN wallets w ON u.id = w.user_id`); res.json(list); }); // ================= 3.
